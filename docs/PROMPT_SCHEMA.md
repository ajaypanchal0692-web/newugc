# Prompt Schema

A prompt should be stored as structured data rather than as an unstructured paragraph.

## Required concepts

- `id`: stable identifier
- `title`: human-readable name
- `category`: cinematic, advertising, social, UGC, etc.
- `duration_seconds`: target duration
- `creator`: persona requirements
- `product`: product/reference requirements
- `script`: ordered scenes or beats
- `camera`: framing and movement guidance
- `lighting`: lighting and environment
- `audio`: dialogue, voice and sound guidance
- `output`: aspect ratio and delivery constraints
- `source`: provenance and attribution metadata
- `version`: prompt revision

## Provenance rule

Every imported or adapted prompt should record its source. Do not represent third-party sourced material as original newugc content.
